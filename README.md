# Романтический сайт ♡

Личный подарок для любимой: приветственная страница + счётчик времени в отношениях.

## Структура

- `index.html` — страница приветствия с кнопкой
- `counter.html` — страница со счётчиком дней вместе
- `style.css` — стили
- `script.js` — анимации и логика счётчика

## Как запустить локально

Просто открой `index.html` двойным кликом в браузере.
Счётчик работает без сервера — всё считается в браузере.

## Как поменять дату начала отношений

Открой `script.js`, найди в самом верху строку:

```js
const RELATIONSHIP_START = new Date(2026, 9, 16, 0, 0, 0); // 16 октября 2026
```

Формат: `new Date(год, месяц-1, день, часы, минуты)`.
Месяцы считаются с нуля: январь — 0, февраль — 1, ..., октябрь — 9, декабрь — 11.

Например, 14 февраля 2025:

```js
const RELATIONSHIP_START = new Date(2025, 1, 14, 20, 30);
```

## Как разместить в интернете (бесплатно)

Вариант 1 — GitHub Pages:
1. Создай аккаунт на github.com.
2. Создай новый репозиторий (например `for-my-love`), загрузи туда все файлы.
3. В настройках репозитория: Settings → Pages → Source: main branch → Save.
4. Через минуту сайт будет доступен по адресу `https://твой-логин.github.io/for-my-love/`.

Вариант 2 — Netlify Drop (самый простой):
1. Зайди на app.netlify.com/drop.
2. Перетащи папку с файлами в окно браузера.
3. Сразу получишь ссылку вида `https://random-name.netlify.app`, которую можно отправить девушке.

Вариант 3 — Vercel: аналогично, drag-and-drop папки на vercel.com/new.

## Проверка функциональности

- Кнопка «Открыть нашу историю ♡» → плавная анимация → переход на counter.html.
- Счётчик обновляется каждую секунду и корректен после перезагрузки страницы.
- Адаптивность под телефон проверяется через DevTools (F12 → режим устройства).
- При `prefers-reduced-motion` анимации частиц отключаются.
